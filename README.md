# Python Day 143 - Job Application Tracker

## About
A Python application to manage job applications, update application statuses, search companies, and generate application summaries.

## Features
- Add new job applications
- View all applications
- Update application status
- Search applications by company
- Display status-wise summary
- Save records in CSV format

## Files
- `job_tracker.py` - Main program
- `applications.csv` - Sample application data

## How to Run
Keep both files in the same working directory.

Run:

`python job_tracker.py`

## Concepts
CSV file handling, functions, lists, dictionaries, searching, input validation, and exception handling.
